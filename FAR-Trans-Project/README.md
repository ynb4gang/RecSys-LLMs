# FAR-Trans Lab — Session 1

**Project:** Profile-Aware LLM Re-Ranking for Financial Asset Recommendation

**Research question:** For warm-start investors in FAR-Trans, does an LLM re-ranker using historical purchases, as-of-cutoff customer risk profiles, and asset metadata improve nDCG@10 over the original user-based kNN order, when both use exactly the same set of up to 50 candidates?

**Team:** Носов Владимир Андреевич (leader), Ворожцов Пётр Алексеевич, Шигапова Диана Рашидовна. The leader's Telegram ID is recorded in the private instructor-facing submission rather than the public repository.

**Milestone 1:** definition, data example and comparison complete; no experiment has been conducted. See [full milestone description](docs/milestone-1.md).

**Plan:** Session 2 — reproducible baseline; Session 3 — LLM reranker, risk-profile ablation and failure analysis; Session 4 — report, code, presentation and predictions.

**Official data:** https://researchdata.gla.ac.uk/1658/ (CC BY 4.0). **Official baseline code:** https://github.com/JavierSanzCruza/far-trans

No real dataset, secrets, evaluation scores or model claims are included in this branch.
