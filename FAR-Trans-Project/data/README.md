# Official FAR-Trans data

Download directly from the University of Glasgow: https://researchdata.gla.ac.uk/1658/

Documentation of the actual column names: https://researchdata.gla.ac.uk/1658/2/README.txt

License: CC BY 4.0. Cite Sanz-Cruzado, Droukas and McCreadie (2024).

The actual dataset is **not bundled or reproduced** in this repository. The illustrative JSON is synthetic. Data sources used in the planned research include transactions.csv, customer_information.csv and asset_information.csv. Use timestamp-valid joins to avoid future-information leakage.
